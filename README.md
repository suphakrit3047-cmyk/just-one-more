# Just One More (อีกมวนเดียว)

บอร์ดเกมเกี่ยวกับการติดบุหรี่และการเลิก ผู้เล่นทุกคนเริ่มเกมในสภาพติดบุหรี่อยู่แล้ว แล้วใช้ชีวิต 12 เดือนให้มีความสุขที่สุด ทุกความสุขจากควันมีราคาที่ต้องจ่าย ทั้งเงิน โรค และระดับการติดที่สูงขึ้น

ไฟล์ `index.html` คือเดโมเว็บที่เล่นได้จริง ผลัดกันเล่นบนเครื่องเดียว 1–4 คน เปิดไฟล์ในเบราว์เซอร์ได้เลย ไม่ต้องติดตั้งอะไร มีหน้าสอนเล่นในตัว

## ภาพรวมกฎ

- **ตัวละครและเป้าหมายลับ** ตอนเริ่มแต่ละคนได้ตัวละคร 1 ใบ (เริ่มเกมต่างกัน ทุกคนเห็น) และเป้าหมายลับ 1 ใบ (ทำได้ตอนจบ +3 ถึง +10 ตามความยาก) ทางที่ดีที่สุดเลยเปลี่ยนไปทุกเกม
- **12 เดือน เดือนละ 3 แอคชัน** แต่ละแอคชันเลือกสถานที่ 1 แห่ง: บ้าน, ที่ทำงาน, ร้านสะดวกซื้อ, จุดสูบหลังตึก, ร้านนั่งชิล, คลินิก
- **การ์ดบุหรี่แบบมีช่อง** หนึ่งการ์ดคือหนึ่งซอง สูบ 1 ครั้ง ถ่านไฟเลื่อนไป 1 ช่อง ได้ผลตามไอคอน (ลดความอยาก, โรค)
- **อีกมวนเดียว** สูบต่อช่องถัดไปในแอคชันเดียวกันได้ แต่ทุกช่องที่เพิ่มต้องทอยเต๋า ได้ 1–2 = ไอ โรค +1 และต้องหยุด
- **ความอยาก (0–6)** ขึ้นเองทุกเดือน ถ้าสิ้นเดือนอยู่ 4 ขึ้นไป = อาการถอน ความสุข −2
- **ระดับการติด (1–5)** ยิ่งติดหนัก สูบแล้วยิ่งได้ความสุขน้อย (+4, +3, +2, +1, 0)
- **ชวนสูบ และควันมือสอง** สูบต่อหน้าคนอื่นเสียความสุข และบุหรี่มวนให้โรคกับคนรอบข้าง
- **โรค** โทเคนครบ 3, 6, 9 จั่วการ์ดโรคเรื้อรังที่มีแต้มติดลบ คลินิกลบโทเคนได้แต่รักษาการ์ดโรคไม่หาย
- **การ์ดเดือน** มีผลพิเศษแค่ 4 เดือน: ปีใหม่, สงกรานต์, ตรวจสุขภาพ, โบนัสสิ้นปี
- **การเลิก** ห้ามสูบ 3 เดือนได้โบนัส แข่งกันเลิก คนแรก +16 คนที่สอง +12 ต่อจากนั้น +8 ทุกสิ้นเดือนคนที่เลิกอยู่ต้องทอยต้านใจ 1 ครั้งเสมอ เดือนแรกความอยาก +2 เดือนที่สอง +1 แล้วค่อยลดลง เจอสิ่งยั่วใจต้องทอยเต๋า + ตัวช่วย ให้มากกว่าความอยาก แพ้ครั้งแรกนับเป็นพลาด ต้องนับเดือนใหม่ ครั้งที่สองกลับไปสูบ

**แต้ม = ความสุข + โบนัส − (การ์ดโรค + โทเคนโรค)**

## สถานะ

เดโมสำหรับทดลองกฎ ปรับบาลานซ์รอบแรกจากการจำลองด้วยบอทแล้ว ยังต้องเทสต์กับคนจริง
